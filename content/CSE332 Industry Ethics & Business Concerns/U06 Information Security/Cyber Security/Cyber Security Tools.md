# Protection Tools
- **Firewalls** provide a first line of defense.
- **VPNs** (**Virtual Private Netoworks**) protect data in transit by encrypting connections.
- **Anti-virus** software prevents known threats.
- **Intrusion Detection Systems** (**IDS**) provide real-time threat monitoring.

# Proactive Defence Tools
- **Endpoint Detection and Response (EDR)** identifies and responds to endpoint threats.
- **Vulnerability scanners** detect system weak points.
- **Encryption tools** secure sensitive data.
- **Security Information and Event Management (SIEM)** offers holistic monitoring.
