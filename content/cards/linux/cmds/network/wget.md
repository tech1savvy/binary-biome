Which command is used for downloading files from the internet?

---

```sh
wget
```

---

- Supports protocols: HTTP, HTTPS, and FTP.
- Non-interactive: Can run in the background without user input, useful for automated and scheduled downloads.
- Resumes interrupted downloads.
- Can download entire websites by following links recursively.
