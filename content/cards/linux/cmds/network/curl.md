Which command-line tool is used for transferring data to or from a server using various internet protocols?

---

```sh
curl <URL>
```

- Make different types of requests (_GET, POST, PUT, DELETE_), upload/download files, interact with APIs, handle authentication, cookies, and proxies.

---

- `cURL` stands for _Client URL_.
- **Protocols supported**: HTTP, HTTPS, FTP, SCP, SFTP, and many others.
