What is the entry point of a Java program and what is its syntax?

---

- The `main` method is the entry point for a Java application.
- Syntax:
  ```java
  public static void main(String[] args) {
      // code
  }
  ```

---

- `public`: It is an access modifier, which means the method is accessible from anywhere.
- `static`: It indicates that the method belongs to the class rather than an instance of the class.
- `void`: It means the method does not return any value.
- `String[] args`: It is an array of strings that can be used to pass command-line arguments.
