How to find the size of an array in Java?

---

You can find the size of an array in Java using the built-in `length` property.

```java
int[] myArray = {1, 2, 3, 4, 5};
int size = myArray.length;
System.out.println("Array size: " + size);  // Output will be 5
```

---

- `length` is a property, not a method, so it is accessed without parentheses.
- It returns the total number of elements the array can hold.
- This property works on all array types in Java.
