How to use a `while` loop in Java?

---

The `while` loop is used to repeat a block of code as long as a condition is true.

**Syntax:**
```java
while(condition) {
    // body of the loop
}
```

**Example:**
```java
int i = 0;
while(i <= 20) {
   System.out.println(i);
   i++;
}
```
