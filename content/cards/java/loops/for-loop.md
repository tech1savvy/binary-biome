How to use a `for` loop in Java?

---

The `for` loop is used to iterate over a range of values.

**Syntax:**
```java
for (initialization; condition; update) {
    // body of-loop
}
```

**Example:**
```java
for (int i = 1; i <= 20; i++) {
   System.out.println(i);
}
```
