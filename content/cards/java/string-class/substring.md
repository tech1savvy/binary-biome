How to get a substring from a string?

---

Use the `substring()` method.

```java
String name = "AmanAndAkku";
System.out.println(name.substring(0, 4)); // Output: Aman
```

---

- The first parameter is the starting index (inclusive).
- The second parameter is the ending index (exclusive).
