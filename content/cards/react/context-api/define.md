What is React Context API and Why it is used?

---

- enables sharing data globally across the component tree without the need to pass props manually at every level.
- helps solve the problem of "prop drilling," where data has to be passed through many intermediate components just to reach a deeply nested one
- creates global-like variables accessible to any component within its provider.
