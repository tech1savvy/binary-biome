### How do I export and import Grafana dashboards via the UI?

---

**Export:**
Open dashboard → top-right **Export** → select **Export as code** → **JSON** → click **Save to file**

**Import:**
**Dashboards** → **New** → **Import** then choose one of:
- Paste JSON
- Upload `.json` file
- Enter dashboard ID (Grafana library)

Select data source(s) if prompted → click **Import**
