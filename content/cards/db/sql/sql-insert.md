###### What is the **INSERT INTO statement** in SQL?

INSERT INTO is used to add new records to a table. You must specify the table and the fields where you want to add values, listing column names followed by corresponding values in parentheses.

***

###### How do you **insert a new record** into a table?

```sql
INSERT INTO heroes(id, name, superpower)
VALUES (1, 'Clark Kent', 'Super Strength');
```

***

###### What is another example of **inserting data**?

```sql
INSERT INTO students(student_id, first_name, last_name, grade_level)
VALUES (1001, 'Harry', 'Potter', 5);
```
