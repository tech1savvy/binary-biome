###### How do you write a **single-line comment** in Python?
***
Use `#` to write a comment. Everything after `#` on that line is ignored.
```python
# This is a comment
name = "Boots"  # This is an in-line comment
```

###### How do you write a **multi-line comment** in Python?
***
Use triple quotes `"""` or `'''` to create a multi-line string (docstring).
```python
"""
This is a multi-line comment.
It spans multiple lines.
"""
print("Pythogoras was here")
```
