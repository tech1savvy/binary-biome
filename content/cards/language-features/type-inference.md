What is the process of automatically detecting the data type of an expression in a formal language?

---

- Type inference (or type reconstruction)

---

- It refers to the automatic detection of the type of an expression without explicit type annotations.

## Supported Languages

- Go
- Rust
- TypeScript
- Swift
- Kotlin
- Haskell
- C++ (via `auto`)
- Java (via `var`)

## Unsupported / Explicit Typing (Historical/Strict)

- C (Standard)
- Assembly
- Pascal

## Dynamic Typing (Runtime Resolution)

- JavaScript
- Python
- Ruby
