What is React Router?

---

React Router is the standard routing library for React. It helps build a user interface that maps to the browser's URL.

Its three main jobs are:

1.  Managing the browser's session history.
2.  Matching the current URL to the correct route.
3.  Rendering the correct nested UI for that route match.
