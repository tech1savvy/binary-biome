### What is a hypervisor and virtualization?

---

**Virtual Machine (VM):** Emulates a physical server, allowing you to install an HTTP server and run applications. Virtualization enables multiple VMs to run on a single physical host by sharing its hardware resources.

**Hypervisor:** Software installed on a physical "host machine" that provisions resources to create and run VMs.

- AWS operates the host machines and the hypervisor layer
- The Guest Operating System (e.g., Linux or Windows) runs on the VM
