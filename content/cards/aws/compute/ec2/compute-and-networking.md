### What is Compute in AWS? What compute services does AWS offer?

---

Compute provides the "brain power" for your application in the form of CPU, Memory, and Networking Capacity. This allows the application to process user requests effectively.

**Client-Server Model:** A client sends a request, a server processes it and sends back a response. Common HTTP servers include Apache, Nginx, and IIS.

AWS compute options include:
- **EC2** (Elastic Compute Cloud) for virtual machines
- **ECS** (Elastic Container Service) and **EKS** (Elastic Kubernetes Service) for container services
- **Lambda** for serverless computing

Amazon **VPC** (Virtual Private Cloud) is the service used to create a private, isolated network on AWS.
