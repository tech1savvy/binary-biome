# What are Amazon S3's key strengths for data lakes?

---

- Exabyte-scale object storage
- High data durability (replication within or across regions)
- Strong read-after-write consistency
- Cost optimization via storage tiers
- Standardized APIs over a serverless architecture
- Data agnostic — stores anything (video, text, sensor, binary, medical, social media)
