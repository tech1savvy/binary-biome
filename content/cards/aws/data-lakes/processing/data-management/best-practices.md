# What are the four best practices for managing data in a data lake?

---

- **Formatting** — use columnar storage formats
- **Partitioning** — organize data by frequently-queried columns
- **Compression** — reduce storage footprint with Snappy, LZO, GZIP
- **Compaction** — merge small files into fewer, larger ones
