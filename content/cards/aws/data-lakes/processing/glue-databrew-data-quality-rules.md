###### How do DataBrew data quality (DQ) rules work?

---

Create rulesets that validate data meets expected standards, e.g. no duplicate rows, no missing values, numeric fields contain acceptable values (e.g. Quantity > 0).

DataBrew suggests recommended rules like duplicate row detection and zero-value checks. Results show pass/fail rates per rule (e.g. 99% success). Failed rules flag rows needing additional transformation.
