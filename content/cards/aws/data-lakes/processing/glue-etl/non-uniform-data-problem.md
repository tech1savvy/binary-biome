# What problem does data transformation solve?

---

- Sources produce data in inconsistent formats: dates (DD/MM vs MM/DD), phone numbers, postal codes
- Data engineers spend ~80% of time collecting, cleaning, and organizing data
- ETL solves this by normalizing everything into a uniform structure
