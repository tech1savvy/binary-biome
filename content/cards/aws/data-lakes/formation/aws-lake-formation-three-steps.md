# What are the three steps to set up a data lake with Lake Formation?

---

- **Register** designated S3 storage locations
- **Create** one or more databases in the Lake Formation Data Catalog (tables generated automatically via blueprints)
- **Grant permissions** to data lake resources at database, table, or column level
