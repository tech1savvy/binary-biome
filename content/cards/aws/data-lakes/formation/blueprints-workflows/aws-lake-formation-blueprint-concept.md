# What is an AWS Lake Formation blueprint?

---

- A pre-built template with everything laid out for building a data lake: storage (S3/Redshift), Glue ETL jobs, Athena queries, crawling/cataloging, and security/access controls.
- No need to figure it all out from scratch.
