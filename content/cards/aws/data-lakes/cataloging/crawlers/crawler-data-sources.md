# What data sources can an AWS Glue Crawler connect to?

---

- **Native clients**: Amazon S3, Amazon DynamoDB
- **JDBC driver**: Amazon RDS, Amazon Aurora, MariaDB, Microsoft SQL Server, MySQL, Oracle, PostgreSQL
- **MongoDB compatibility mode**: MongoDB, Amazon DocumentDB
