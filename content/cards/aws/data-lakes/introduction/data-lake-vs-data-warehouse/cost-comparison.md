# How does cost differ between data warehouse and data lake?

---

- **Data warehouse**: traditional DB billing — pay for compute and storage continuously. Costs can grow large with performance and storage needs.
- **Data lake**: cost-effective storage (e.g. Amazon S3). Pay for compute only when analyzing data.
