###### What AWS services enable unified data access?

---

- **AWS Glue** — ETL
- **Amazon Data Firehose** — data streaming
- **AWS DMS** — database migration
- **AWS Transfer Family** — file transfers
- **Amazon MSK** — managed Apache Kafka
- **Amazon AppFlow** — SaaS integrations

Goal: access data where it resides and move it selectively when needed.
