# What are the key categories of modern data architecture on AWS?

---

- **Scalable data lakes** — secure storage + metadata management (S3, Lake Formation, Athena)
- **Purpose-built analytics** — right tool for each use case (Aurora, DynamoDB, OpenSearch, EMR, Redshift, SageMaker, MSK, Kinesis)
- **Unified data access** — query data in place, move selectively (Glue, Firehose, DMS, Transfer Family, MSK, AppFlow)
- **Unified governance** — authorize, manage, audit access (Lake Formation)
- **Performance & cost** — compression, partitioning, columnar formats, billing alerts
