###### What are the key categories of modern data architecture on AWS?

---

1. **Scalable data lakes** — secure storage + metadata management (S3, Lake Formation, Athena)
2. **Purpose-built analytics** — right tool for each use case (Aurora, DynamoDB, OpenSearch, EMR, Redshift, SageMaker, MSK, Kinesis)
3. **Unified data access** — query data in place, move selectively (Glue, Firehose, DMS, Transfer Family, MSK, AppFlow)
4. **Unified governance** — authorize, manage, audit access (Lake Formation)
5. **Performance & cost** — compression, partitioning, columnar formats, billing alerts
