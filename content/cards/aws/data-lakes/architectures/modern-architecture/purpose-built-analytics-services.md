# What AWS services provide purpose-built analytics?

---

- **Amazon Aurora** / **DynamoDB** — databases
- **Amazon OpenSearch Service** — search
- **Amazon EMR** — big data processing
- **Amazon Redshift** — data warehousing
- **Amazon SageMaker** — machine learning
- **Amazon MSK** — streaming
- **Amazon Kinesis Data Analytics** — real-time analytics on streaming data
