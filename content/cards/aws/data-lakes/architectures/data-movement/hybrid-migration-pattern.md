# What is the hybrid migration pattern for moving to a data lake?

---

- Use Athena Federated Queries as a bridge: join cloud data (S3) with on-premises data during migration.
- Continue centralizing data to S3 for centralized governance with Lake Formation, better query performance, and simplified permissions.
