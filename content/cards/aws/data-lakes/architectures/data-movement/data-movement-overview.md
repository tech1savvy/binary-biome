# What are the three data movement scenarios in a data lake architecture?

---

- **Inside-out** — data departs from the data lake to other services for external consumption
- **Outside-in** — data from external sources is ingested into the data lake for processing
- **Around the perimeter** — services share data directly with each other, data doesn't always traverse the lake
