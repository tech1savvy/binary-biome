# What is outside-in data movement?

---

- External data sources are ingested into the data lake for internal analysis.
- Data primarily exists elsewhere; the lake is engaged when there's something to process.
- Example: copy DB query results into the data lake to run ML recommendation algorithms with SageMaker, Glue, or EMR.
