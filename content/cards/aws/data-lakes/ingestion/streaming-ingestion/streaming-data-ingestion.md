# What AWS service handles streaming data ingestion?

---

- **Amazon Kinesis** — fully managed service to ingest and process streaming data at any scale. Supports video, audio, and real-time processing.
- **Open source alternatives**: FluentD, Apache Sqoop, Apache Kafka
