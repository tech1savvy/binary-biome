# What services handle transactional data (database) ingestion?

---

- **AWS DMS** (Database Migration Service) — managed migration and replication
- **AWS SCT** (Schema Conversion Tool) — automates schema conversion between database engines
- Used together: SCT converts the schema, DMS migrates the data.
