###### What AWS services ingest files and objects into a data lake?

---

- **Amazon AppFlow** — SaaS-to-AWS data exchange (e.g. Salesforce → S3)
- **AWS Transfer Family** — SFTP/FTPS/FTP file transfers
- **AWS Snow Family** — offline bulk upload via physical devices

Open source alternatives: Logstash, Apache Flume, Apache Log4j
