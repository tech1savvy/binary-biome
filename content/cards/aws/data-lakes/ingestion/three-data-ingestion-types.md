# What are the three main data types for ingestion?

---

- **Files & Objects** — existing files (pictures, videos, PDFs, logs, text)
- **Transactional Data** — database migrations with reads/writes replicated
- **Streaming Data** — real-time data as it's created (IoT, clickstream, gaming)
