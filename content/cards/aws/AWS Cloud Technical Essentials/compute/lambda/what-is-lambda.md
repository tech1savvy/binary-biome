### What is AWS Lambda?

---

AWS Lambda allows you to run code without provisioning or managing servers. You only pay for the compute time you consume — there is no charge when your code is not running.

**Key Characteristics:**
- **Event-Driven:** Lambda functions run in response to triggers
- **Serverless:** Infrastructure management is entirely handled by AWS
- **Short-lived:** Currently has a 15-minute maximum runtime per execution
- **No Idle Costs:** You only pay for requests and execution duration
