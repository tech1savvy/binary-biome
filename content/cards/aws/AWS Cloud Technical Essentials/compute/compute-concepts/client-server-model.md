### What is the client-server model?

---

Applications are powered by servers that handle requests and send responses.

- **Client:** A person or computer that sends a request (e.g., a web browser)
- **Server:** A computer (or cluster of computers) connected to the internet that processes requests and serves responses (e.g., a website)
- **Resources:** Servers provide **CPU**, **Memory**, and **Networking Capacity** to process transactions
- **Common HTTP Servers:**
  - **Windows:** Internet Information Services (IIS)
  - **Linux:** Apache HTTP Web Server, Nginx, Apache Tomcat
