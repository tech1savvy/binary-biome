### What are the EC2 instance families?

---

| Instance Family | Common Codes | Description | Typical Use Cases |
| :--- | :--- | :--- | :--- |
| **General Purpose** | T, M, A, Mac | Balanced compute, memory, and networking | Web servers, dev environments, small databases |
| **Compute Optimized** | C | High-performance CPUs | Batch processing, gaming servers, HPC |
| **Memory Optimized** | R, X, Z | Large memory capacity for in-RAM datasets | In-memory databases, big data analytics |
| **Accelerated Computing** | P, G, F, Inf | Hardware accelerators (GPUs, FPGAs) | ML, graphics rendering, video work |
| **Storage Optimized** | I, D, H | High throughput, low-latency storage, high IOPS | NoSQL databases, data warehousing, log processing |
