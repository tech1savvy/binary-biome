### What is an Amazon Machine Image (AMI)?

---

**AMI** stands for Amazon Machine Image — the foundational template for an EC2 instance, containing the OS and initial software.

- **Relationship:** The AMI is the **Class** (recipe); the EC2 instance is the **Object** (cake)
- **Reusability:** You can create a custom AMI from a configured instance to launch identical copies, reducing errors
- **Regional Scope:** AMI IDs are unique to each AWS Region
