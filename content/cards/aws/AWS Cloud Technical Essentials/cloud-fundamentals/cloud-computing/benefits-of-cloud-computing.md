### How does cloud computing change spending on resources?

---

trade capital expense for variable expense, paying only for the resources they consume

### How do economies of scale benefit cloud users?

---

lower pay-as-you-go prices

### How does cloud computing handle capacity planning?

---

eliminates capacity guessing by allowing resources to scale up or down within minutes

### How does cloud computing affect speed and agility?

---

increases speed and agility by reducing resource provisioning time from weeks to minutes

### What physical burden does cloud computing remove?

---

reduces the need to run and maintain physical data centers
