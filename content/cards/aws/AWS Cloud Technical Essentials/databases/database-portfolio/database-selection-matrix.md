### What are the AWS database types and their services?

---

| Database Type | Use Cases | AWS Service |
| :--- | :--- | :--- |
| **Relational** | Traditional apps, ERP, CRM, E-commerce | Amazon RDS, Amazon Aurora, Amazon Redshift |
| **Key-Value** | High-traffic web apps, gaming, e-commerce | Amazon DynamoDB |
| **In-Memory** | Caching, session management, leaderboards | Amazon ElastiCache (Redis/Memcached) |
| **Document** | Content management, catalogs, user profiles | Amazon DocumentDB (MongoDB compatible) |
| **Wide Column** | Industrial apps, fleet management, route optimization | Amazon Keyspaces (Cassandra compatible) |
| **Graph** | Fraud detection, social networks, recommendations | Amazon Neptune |
| **Time Series** | IoT apps, DevOps, industrial telemetry | Amazon Timestream |
| **Ledger** | Systems of record, banking, supply chain | Amazon QLDB |
