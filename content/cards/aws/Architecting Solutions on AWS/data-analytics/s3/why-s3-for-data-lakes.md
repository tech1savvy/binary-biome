### Why S3 for Data Lakes

---

**Decoupled Architecture**

- Multiple analytics tools can read the same dataset

Examples:

- Athena
- EMR
- SageMaker

**Durability**

- 99.999999999% (11 nines)

**Usage-Based Pricing**

- Pay only for stored data and requests

**Storage Tier Optimization**

- Intelligent-Tiering moves objects automatically between tiers

**Regional Resource**

- Buckets exist at the region level
- No AZ management required
