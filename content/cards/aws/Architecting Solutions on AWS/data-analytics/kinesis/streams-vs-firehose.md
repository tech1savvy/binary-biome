### Streams vs Firehose

---

| Feature        | Data Streams              | Data Firehose         |
| -------------- | ------------------------- | --------------------- |
| Management     | Requires setup & code     | Fully managed         |
| Latency        | < 1 second                | ~60 sec+              |
| Data retention | Configurable (hours–days) | Temporary buffer only |
| Scaling        | Shard-based scaling       | Automatic             |
