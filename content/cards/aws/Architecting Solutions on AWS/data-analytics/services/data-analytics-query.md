### Data Analytics & Query

---

**Amazon Athena**

- Serverless SQL queries on S3 data
- Pay per data scanned

**Amazon EMR**: (Elastic MapReduce)

- Big data processing platform
- Uses frameworks like:
  - Spark
  - Hive
  - Presto

**Amazon OpenSearch Service**

- Real-time search and log analytics
- Used for monitoring and dashboards
