### Key Settings

---

| Setting            | Purpose                            | Range           |
| ------------------ | ---------------------------------- | --------------- |
| Visibility Timeout | Hide message while being processed | 0 sec – 12 hrs  |
| Message Retention  | Time message stays in queue        | 1 min – 14 days |
| Wait Time          | Long polling duration              | 0 – 20 sec      |
| Max Message Size   | Size of message                    | 1 KB – 256 KB   |
| Delivery Delay     | Delay message availability         | 0 – 15 min      |
