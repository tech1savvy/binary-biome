### AWS Control Tower

---

Purpose:: Automate creation and governance of AWS accounts.
<!--SR:!2026-03-10,4,270-->

Often called:
**Account Vending Machine**.

Main features:

Landing Zone

- preconfigured multi-account environment.

Account Provisioning

- creates new accounts using AWS Organizations.

Guardrails

- preventive guardrails → Service Control Policies (SCP)
- detective guardrails → AWS Config rules.

Drift Detection

- detects when accounts deviate from required configuration.

Dashboard

- shows organization-wide compliance status.
