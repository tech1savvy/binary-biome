### Key AWS Services

---

**AWS Organization**

- manages multiple AWS accounts.

**AWS Control Tower**

- automates landing zone setup
- provisions new accounts.

**IAM Identity Center**

- centralized user access management (SSO).

**AWS Service Catalog**

- standardized approved services.

**AWS CloudTrail**:: records account activity and API calls.
<!--SR:!2026-03-09,3,250-->

**CloudWatch Logs**

- centralized log storage and monitoring.
