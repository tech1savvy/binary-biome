### 1. IT Operating Models

---

Defines responsibility split between application teams and platform teams.

Traditional Ops

- Application team builds code only.
- Operations team manages infrastructure and platform.

CloudOps

- Application team manages both development and operations for the app.
- Platform team manages cloud infrastructure.

DevOps

- Application teams manage:
  - application code
  - app-specific infrastructure.

- Platform team manages:
  - shared infrastructure
  - core platform services.

Goal:
faster delivery and shared responsibility.
