### 3. Service Quotas & API Limits

---

**Service Quotas**:: maximum number of resources allowed per account.
<!--SR:!2026-03-09,3,250-->

Examples:

- number of EC2 instances
- number of S3 buckets
- vCPU limits.

API Rate Limits

- limit on API calls per second.

Example:
too many automation scripts can trigger throttling.
