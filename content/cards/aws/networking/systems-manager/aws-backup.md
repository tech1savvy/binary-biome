### AWS Backup

---

Centralized backup service.

Purpose:
Manage backups across AWS services and hybrid workloads.

Supports backups for:

- S3
- RDS
- EBS
- DynamoDB
- Storage Gateway
- VMware workloads

Features:

- policy-based backups
- centralized console
- retention & compliance controls.
