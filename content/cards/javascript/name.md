Why is it called JavaScript?

---

- Initially named "LiveScript".
- But Java was very popular at that time, so it was decided that positioning a new language as a “younger brother” of Java would help.
- Therefore renamed to "JavaScript"

---

- JavaScript evolved into an independent language with its own specification, ECMAScript.
- It now has no relation to Java.
