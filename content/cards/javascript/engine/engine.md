What is JavaScript engine?

---

- program responsible to run JavaScript code.
- sometimes also called, JavaScript Virtual Machine

---

- Browser Embedded **Engine Codenames:**
  - _V8_: Chrome, Opera, Edge
  - _SpiderMonkey_: Firefox
  - Chakra: IE
  - JavaScriptCore: Safari
- Standalone Engine:
  - _Node.js_ leverages the V8 engine (originally developed for Chrome) to execute JavaScript code outside the browser for server-side applications.
